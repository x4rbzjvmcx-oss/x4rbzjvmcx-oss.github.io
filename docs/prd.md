 # 孙若曦个人网站 — 产品需求文档 (PRD)
 
 ## 1. 项目目标
 建立一个可长期更新的个人主页，集中展示个人背景、专业技能、项目经历和学生工作成果，作为课程作业的同时也为实习招聘和未来项目合作提供可信的线上档案。
 
 ## 2. 目标用户与使用场景
 | 用户类型 | 使用场景 | 最先寻找的信息 |
 |---------|---------|--------------|
 | **课程教师** | 按作业要求检查项目完整性和过程材料 | PRD/Design/Checklist 文档、Git 提交记录、Pages 可访问性 |
 | **实习招聘者（HR/技术面试官）** | 快速了解候选人能力匹配度 | 专业技能、项目经历、竞赛成果 |
 | **未来项目伙伴** | 判断合作潜力和兴趣方向 | 项目方向、技术栈、联系方式 |
 
 ## 3. 本期范围（本学期必须包含）
 - [x] **Hero 区域**：姓名、一句话定位、求职意向
 - [x] **About 区域**：个人简介、教育背景
 - [x] **Skills 区域**：技术技能、商科技能、数学基础
 - [x] **Projects 区域**：3 个项目经历
 - [x] **Experience 区域**：学生工作与领导经历
 - [x] **Education 区域**：深圳大学信息管理与信息系统
 - [x] **Contact 区域**：公开联系方式（邮箱、GitHub、LinkedIn）
 - [x] **过程文档**：PRD、Design、Checklist、最终报告
 - [x] **截图证据**：桌面端、移动端、Pages 状态、Checklist
 
 ## 4. 本期明确不做什么
 - ❌ 不开发登录、注册、数据库或支付功能
 - ❌ 不添加评论区或访客追踪
 - ❌ 不引入复杂前端框架（保持 Jekyll + GitHub Pages）
 - ❌ 不公开私人手机号、住址、身份证件
 - ❌ 不包含课程邀请码、API Key 或 Token
 
 ## 5. 成功标准
 - ✅ GitHub Pages 可公开访问，链接写入 README
 - ✅ 首页五个基础区块齐全，无占位文字或虚构经历
 - ✅ 所有导航链接和项目链接有效
 - ✅ 桌面端和移动端均可正常阅读，无横向溢出
 - ✅ docs/ 三份文档齐全，内容与最终网站一致
 - ✅ report/final-report.md 覆盖项目全流程
 - ✅ screenshots/ 至少 4 张清晰截图
 - ✅ Git 至少 3 次有意义提交
 
 ## 6. 隐私边界
 - 公开内容：姓名、学校、专业、项目经历、竞赛奖项、学生工作、邮箱（带掩码）、GitHub 链接
 - 不公开：手机号（138****4770）、详细住址、身份证号、课程邀请码、个人密码
 
 ## 7. 技术选型
 - **框架**：Jekyll（远程主题 sproogen/resume-theme）
 - **托管**：GitHub Pages（自动构建）
 - **配置中心**：`_config.yml`（个人信息、社交链接、内容区块均在此定义）
 - **样式覆盖**：`assets/main.scss`
 - **版本控制**：Git + GitHub
