 # 孙若曦个人网站 — 设计说明 (Design)
 
 ## 1. 页面区块与浏览顺序
 页面采用单页滚动布局，从上到下的浏览顺序为：
 
 1. **Hero** — 姓名、一句话定位、求职意向（"HR-AI 实习生 / 数据分析实习生"）
 2. **About** — 个人简介、教育背景、专业排名
 3. **Skills** — 技术栈（C/C++、数据可视化、AI/ML等）、商科基础、数学基础
 4. **Projects** — 3 个项目卡片（HR Analytics、消费补贴研究、社会实践）
 5. **Experience** — 学生工作（支教部长、秘书部部长）
 6. **Education** — 深圳大学信息管理与信息系统
 7. **Contact** — 邮箱、GitHub、LinkedIn
 8. **Footer** — 版权声明
 
 ## 2. 颜色、字体与整体风格
 
 ### 配色方案（清新风格）
 | 用途 | 颜色 | 色值 | 说明 |
 |------|------|------|------|
 | **主色** | 柔和薄荷绿 | `#6ABF8B` | 用于标题强调、按钮、链接等关键元素 |
 | **辅助色** | 暖白 | `#F8F9FA` | 页面背景、卡片背景 |
 | **强调色** | 清透蓝 | `#4A90D9` | 用于图标、次要强调 |
 | **文字主色** | 深灰 | `#2D3436` | 正文文字 |
 | **浅色文字** | 浅灰 | `#636E72` | 辅助说明文字 |
 
 ### 字体
 保留模板默认的系统字体栈，无需引入外部字体库。
 
 ### 整体风格
 清爽、简洁、留白充分，"薄荷+白衬衫"的视觉感受。
 
 ## 3. 桌面端和移动端要求
 - **桌面端**：宽屏布局（≥1024px），最多两栏内容对齐
 - **移动端**：单栏布局（≤768px），文字自动换行，无横向溢出
 - **交互**：导航可点击、链接可跳转、社交图标清晰可辨
 
 ## 4. 关键文件职责
 | 文件 | 职责 |
 |------|------|
 | `_config.yml` | **所有内容数据的唯一源头**：个人信息、社交链接、About 文字、Projects、Experience、Education |
 | `index.md` | 页面入口，`layout: default` 使 Jekyll 使用主题首页布局 |
 | `assets/main.scss` | 样式覆盖。通过 `@import` 导入主题样式，在此文件中覆盖颜色变量 |
 | `images/` | 头像（profile.jpg）、favicon 等静态资源 |
 | `Gemfile` | 声明 `github-pages` gem，GitHub 自动读取并构建 |
 
 ## 5. 保留与修改计划
 | 保留 | 修改 |
 |------|------|
 | 模板整体布局与响应式结构 | 替换全部个人信息（→ 孙若曦） |
 | Jekyll 远程主题机制 | 替换全部项目/经历/教育占位内容 |
 | GitHub Pages 构建配置 | 修改配色方案为薄荷绿+蓝 |
 | 默认字体栈 | 替换头像照片 |
 | SEO 插件配置 | 新增 docs/、report/、screenshots/ 目录 |
 
 ## 6. 图片与外部素材
 - **头像**：本人照片（需用户提供）
 - **背景/图标**：模板自带素材，确认 License 允许使用和修改
 - **图标库**：Font Awesome（模板已内置，来自主题依赖）
 - 不使用任何未授权第三方图片
