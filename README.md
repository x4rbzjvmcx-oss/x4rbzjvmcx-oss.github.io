 # 孙若曦的个人网站
 
 个人主页，集中展示个人背景、专业技能、项目经历和学生工作成果。
 
 ## 所用模板
 - [Modern Resume Theme](https://github.com/sproogen/modern-resume-theme)
 
 ## 主要修改内容
 - 替换全部个人信息为孙若曦的真实资料
 - 替换 Projects 为 3 个实际项目经历
 - 替换 Experience 为学生工作经历
 - 替换 Education 为深圳大学信息管理与信息系统
 - 配色改为薄荷绿 + 清透蓝（清新风格）
 - 新增 docs/ 目录（PRD / Design / Checklist）
 - 移除模板占位内容与社交链接

 ## 隐私说明
 本仓库不包含以下内容：
 - 个人手机号、住址、身份证件
 - 课程邀请码、API Key、Token 或密码
 - 任何不应公开的个人隐私数据
 
 ## 本地使用
 本项目基于 Jekyll + GitHub Pages，推送到 main 分支后自动构建。
 如需本地预览，请安装 Ruby + Bundler，然后：
 ```bash
 bundle install
 bundle exec jekyll serve
 ```
